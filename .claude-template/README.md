# Claude Code Configuration Template

Copy only the pieces your project needs into a project-local `.claude/` directory.
The checked-in `settings.json` is intentionally conservative and grants no extra
permissions.

- `agents/agent-template.md` shows the shape of a custom subagent definition.
- `skills/skill-template/SKILL.md` shows the minimum structure of a skill.

Hooks are platform-specific, so no hook command is enabled here. Consult the current
Claude Code hook documentation and review every command before adding it.

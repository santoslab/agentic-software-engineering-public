# Module: Agentic Software Engineering Principles

A new treatment of the software engineering concepts of the course, built
around one running example, the message guard, that grows version by version.
It is under development and is not yet referenced from the course web page;
`module-software-engineering/` remains the module taught this semester.

What is here:

- `demos/running-example-message-guard/` — the running example, one snapshot
  directory per version. Version A0 is complete.
- `lecture-notes/` — student-facing notes, one file per lecture. Lecture 01
  (intent, specifications, realizations, and the five judgments, on A0) is
  drafted.
- The design that the module follows is
  `software-engineering/running-example-design.md` at the repository root; the
  vocabulary is `glossary.md`.

Instructor outlines and slides will be added as they are written, following
the three-artifact layout of `module-software-engineering/`.

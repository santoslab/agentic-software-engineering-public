# The Reversi audit walkthrough (Lecture 05)

One demonstration, run once, on the starter that students receive for Project 1:
the first move of Part 1 — the audit of the Reversi concept-of-operations sketch
(DEV-8) — performed live, with rulings on four scripted gaps and one deferral,
and stopped before `CONOPS.md` is written. The rest is the homework.

| File | What it is |
|---|---|
| `demo-script-lecture-05.md` | The script: setup, four segments, prompts, recoveries |
| `expected-gaps.md` | The instructor key: 26 decisions the sketch leaves open, the standard rulings, which are the student's choice, and nudges. Not student-facing |

The starter is not duplicated here. It is
`../../student-materials/reversi-starter/` — the sketch, the loader `CLAUDE.md`,
`process/` (the L04 set, identical to the game demo's `reference/process/`),
and `BACKLOG.md`. The brief is `../../project-1-reversi-brief.md`.

`process/` in the starter is installed from the template set and is not edited
here; a rule changes in the template and is re-installed.

# The Reversi walkthrough (Lecture 05)

One demonstration, run once, that reads the Project 1 brief in order. Step 1 is
shown on Reversi only as far as reading the sketch — sorting §4.2 and finding
its tension; the prompt, rulings, a deferral, and an RPT-3 proposal are shown in
their form on tic-tac-toe, from *Specifying a Game*. No Reversi gap list or
ruling is shown: those are the students' work. Steps 2 to 5 are shown by opening the
finished tic-tac-toe game's artifacts (`../lecture-03-game-demo/reference/`) at the section
the brief names as the model for each step. The rest is the homework.

| File | What it is |

| `demo-script-lecture-05.md` | The script: what is live and what is from files, setup, seven segments, prompts, recoveries |
| `expected-gaps.md` | The instructor key: 26 decisions the sketch leaves open, the standard rulings, which are the student's choice, and nudges. Not student-facing |

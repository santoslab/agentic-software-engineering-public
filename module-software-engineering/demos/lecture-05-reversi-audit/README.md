# The Reversi walkthrough (Lecture 05)

One demonstration, run once, that reads the Project 1 brief in order. Step 1 —
the audit of the Reversi concept-of-operations sketch (DEV-8), rulings on four
scripted gaps, one deferral, and one ruling carried to an RPT-3 proposal — is
shown from captures taken at rehearsal on the starter students receive, and
stops before `CONOPS.md` is written. Steps 2 to 5 are shown by opening the
reference game's artifacts (`../lecture-03-game-demo/reference/`) at the section
the brief names as the model for each step. The rest is the homework.

| File | What it is |
|---|---|
| `demo-script-lecture-05.md` | The script: what is live and what is from captures, setup, seven segments, prompts, recoveries |
| `expected-gaps.md` | The instructor key: 26 decisions the sketch leaves open, the standard rulings, which are the student's choice, and nudges. Not student-facing |

The captures (C1 to C4) are taken at rehearsal and are not checked in, as with
the other demos.

The starter is not duplicated here. It is
`../../student-materials/reversi-starter/` — the sketch, the loader `CLAUDE.md`,
`process/` (the L04 set, identical to the game demo's `reference/process/`),
`BACKLOG.md`, and the gate's configuration. The brief is
`../../project-1-reversi-brief.md`.

`process/` in the starter is installed from the template set and is not edited
here; a rule changes in the template and is re-installed.

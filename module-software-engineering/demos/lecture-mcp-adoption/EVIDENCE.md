# Documentation tool evidence

- Date, host/model version, and task:
- Repository configuration (no secrets):
- Server connection status and actual discovered tool:
- Exact prompt:
- Actual tool name and arguments:
- Relevant result excerpt or sanitized screenshot:
- Source URL and passage checked:
- Final answer:
- Why that result supports or contradicts the answer:
- Failure layer and diagnostic step if unsuccessful:

Distinguish live use, LLM-free protocol use, recorded evidence, and a constructed
teaching example. A citation or a connected status alone does not establish that
the model used the configured integration.

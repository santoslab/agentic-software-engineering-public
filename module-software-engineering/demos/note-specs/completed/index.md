# Note Set Index

Study notes on software-engineering classics, maintained by the agent per
`note-set-conops.md` and `note-format-spec.md`.

- [No Silver Bullet](notes/no-silver-bullet.md) — Brooks divides software difficulty into essence and accident and predicts no order-of-magnitude gain from any single technique.
- [Royce 1970 Waterfall Paper](notes/royce-1970-waterfall-paper.md) — The paper cited as waterfall's origin actually calls the single-pass approach risky and prescribes feedback between phases and building a pilot version first.
- [Lehman's Laws of Software Evolution](notes/lehmans-laws-of-software-evolution.md) — Lehman's laws say a used system must continually change or decay, and grows more complex unless work is done to reduce it.

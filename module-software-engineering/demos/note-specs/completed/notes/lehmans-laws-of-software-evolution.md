# Lehman's Laws of Software Evolution

## Summary

Lehman's laws say a used system must continually change or decay, and grows
more complex unless work is done to reduce it. A specification is a used
artifact too, and escapes the same decay only through continual maintenance.

## The laws

Lehman observed that software used in the real world obeys laws of its own.
The first, Continuing Change: a system that is used must be continually
adapted, or it becomes progressively less useful in its environment. The
second, Increasing Complexity: as a system evolves, its complexity increases
unless work is done to reduce it.

## Why this course cares

A specification is a used artifact too, and it obeys the same law: either it
is continually adapted alongside the system it describes, or it decays into
fiction. Maintaining spec–implementation conformance as an invariant is how
we choose the first branch.

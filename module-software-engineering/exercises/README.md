# Exercise specifications

This folder holds the exercise specs for the module.

- File naming: `exercise-NN-<slug>.md`.
- Header: a blockquote with `**Assigned:** Lecture NN · **Due:** ... · **Effort:** ...`
  and a `**Requires:**` line when the exercise needs tooling or accounts.
- Body: a `## Deliverable` section listing the files to submit and a
  `## Completion checklist` of `- [ ]` items. Grading is completion-based:
  satisfactory means every checklist item is present and honestly reported.
- Reference example: `../../weeks-01-03/exercises/exercise-02-codebase-comprehension.md`.

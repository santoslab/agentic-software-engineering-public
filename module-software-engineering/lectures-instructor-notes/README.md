# Instructor lecture outlines

This folder holds the outline-level lecture plans for the instructor: timings, demo
setup and fallbacks, discussion prompts, and cut-if-long notes. It plays the role that
`lectures/` plays in `weeks-01-03/` and `weeks-04-07/`.

- File naming: `lecture-NN-<slug>.md`, numbered `01` through `06` within this module.
- Format: `../../templates/lecture-outline-template.md`. Use
  `**Unit:** module-software-engineering` in the header line.
- Each outline has a matching student lecture-notes file in `../lecture-notes/` and a
  slide deck in `../slides/`.

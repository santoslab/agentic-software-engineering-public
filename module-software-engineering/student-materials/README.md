# Student Materials

Handouts and small example artifacts distributed with this module's exercises. None
contains a reference solution.

| File or folder | Lecture / exercise | Contents |
|---|---|---|
| [`handout-lecture-01-note-set-starter-specs.md`](handout-lecture-01-note-set-starter-specs.md) | Lecture 01, Exercise 1 | The three files the demo starts from (the ConOps, the format specification, and the agent's working rules), reproduced for reading before class; PDF checked in |
| [`spec-driven-planning-prompt-template.md`](spec-driven-planning-prompt-template.md) | Lecture 01, Exercise 1 | A prompt template for planning and realizing a system from draft specifications, with a filled example and the standing rules that belong in `CLAUDE.md` |

PDF versions of handouts are checked in for direct distribution; the Markdown
files are the editable sources. To rebuild a PDF, run the pandoc command given in
the repository's `CLAUDE.md`.

Exercise specifications live in [`../exercises/`](../exercises/), and the
student-facing prose for each class meeting lives in
[`../lecture-notes/`](../lecture-notes/).

# Fictional music fixture

`fictional-music-v1` is original teaching data generated by `build_fixture.py`.
Artists, track titles, albums, users, playlists, and their relationships are
constructed examples. No Spotify records, recordings, book data, or other music
catalogue were copied into this fixture. Any resemblance of invented names to
real performers is incidental. This dataset says nothing about listening habits
or commercial popularity.

The older repository music CSVs motivated the subject, but their distribution
terms were not established for this package. The plan explicitly permits an
original fictional fixture in that case. This version provides complete metadata
and useful overlap without redistributing those records. It includes 36 tracks,
8 artists, 6 albums, 8 playlists, and 4 users. Two playlists deliberately have
the same name. IDs remain distinct.

Three CSV rows repeat an identical playlist/track/position tuple. Loading collapses
those duplicates. P01 deliberately contains T01 at positions 1 and 11; those are
two occurrences, but one distinct track. Twelve tracks have a second artist
credit, represented as an additional metadata row. Preserve both credits.

The generator and scripts use the course's MIT code boundary. The original CSV
data in this directory is made available under the same MIT terms, with copyright
attribution to the course contributors upon publication. Instructional prose and
media follow the course's CC BY 4.0 boundary. No external dataset attribution is
required for this original fixture; do not apply the airline OpenFlights notice.

Rebuild from the homework directory:

```sh
uv run --frozen python fixture/build_fixture.py
```

The manifest records source version, row counts, SHA-256 hashes, graph counts,
source playlist P01, and duplicate policy. It is deterministic: regeneration
should produce byte-identical CSVs and manifest. `database.py` validates hashes
before connecting. Keep generated data and generator together in student exports.

# ASE Project - General Guidance and Timeline

## Purpose and expected content

The purpose of the project is to allow you to apply agentic software engineering techniques to a software development project that is meaningful to you.
This could be a project that you have already started and you want to accelerate, or it could be new development.

We expect that it will be of a size that provides meaningful challenges (not a toy example).
Ideally, the project will involve multiple technologies and multiple layers, e.g.,
 - a backend (ideally, related to Neo4j)
 - some sort of data manipulation and data structure declaration
 - a frontend (e.g., some UI)

We expect that you will apply some of the key concepts that you are learning in class related to spec-driven development.
-  you will work with the agent to brainstorm possible technology solutions and development approaches for your project
- the project should include multiple forms of specifications (e.g., ConOps, Requirements, architecture description, glossary/ontology, state machine) — it doesn’t have to be all of these
  - you will have the agents help you maintain these
- the project should include significant testing infrastructure that you can tie back to specifications
  - you will have the agents help you maintain these
- you will use the agent to help you build special-purpose reports, etc. that help you understand the code base
- you will use the agent to help you develop documentation and examples for your project

## Project Deliverables

- Project proposal: 1-2 page summary in markdown format of the project describing
      - purpose / scope of the system that you want to work on
      - envisioned technologies involved in the system
      - proposed development plan (list of tasks and target dates)
- Initial presentation presenting project concept and plan
- Completed project in a repository with supporting examples, documentation, etc.  in a form work the instructors and our agents can understand you project and run it own examples
- Final presentation providing a walkthrough of the completed project

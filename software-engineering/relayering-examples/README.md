# Examples for the re-layering proposal

Worked examples of the artifacts that
[running-example-relayering.md](../running-example-relayering.md) proposes,
written against the message guard as it stands at A0 and A1. They are for
review; nothing under `module-ase-principles/` has been changed.

| Version | File | What it shows |
|---|---|---|
| A0 | [a0/CLAUDE.md](a0/CLAUDE.md) | the instruction file: the agent's three roles, and the report procedure it follows |
| A0 | [a0/process/judgments.md](a0/process/judgments.md) | five definitions; eight per-form clauses with *Holds when*, *Evaluated by*, *Evidence*, *Example*; no process rules |
| A0 | [a0/process/templates/assurance-report.md](a0/process/templates/assurance-report.md) | the form of the report |
| A0 | [a0/reports/assurance-report.md](a0/reports/assurance-report.md) | a report compiled by an agent against v0, with provenance per row |
| A1 | [a1/CLAUDE.md](a1/CLAUDE.md) | the roles with the two procedures added; no commit trigger |
| A1 | [a1/process/judgments.md](a1/process/judgments.md) | the glossary and scenario forms added; clauses amended; the file arranged by form |
| A1 | [a1/process/procedures.md](a1/process/procedures.md) | the audit and elicitation as procedures with stops and records |
| A2 | [a2/process/rules.md](a2/process/rules.md) | where the ledger rules and the control rules land, in the A1 rule template |
| A2 | [a2/CLAUDE.md](a2/CLAUDE.md) | the one paragraph that control adds to the instruction file |

Identifiers: `ConOps-SQ-1` is a judgment clause (form, judgment, number);
`REQ-1` and `US-3` are specification clauses; `Specs-Audit` is a procedure;
`Ledger-1` and `WF-1` are rules of the A2 layers.
